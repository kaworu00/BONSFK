# 山海引魂录 Demo（Shanhai Valkyrie）

玩法致敬《北欧女神》、**题材与内容完全原创**的 2D 横板动作 RPG，世界观取材自《山海经》。

- **引擎**：Godot 4.3
- **完整闭环**：横板探索 → 招募 12 位山海英灵 → 编队加点 → 回合连击战斗 → 三阶段 Boss 战
- **特色系统**：前后排站位、连段浮空、技能差异化（贯穿/眩晕/灼烧/魅惑）、决之技立绘演出、血量持久化、休息治疗、行商饰品、存档贯通

## 运行

用 Godot 4.3 及以上版本打开本目录（`project.godot`）即可运行。

详细上手指南见 [README_上手说明.md](README_上手说明.md)。
