# 山海引魂录 Demo（北欧女神 1 玩法 × 山海经题材）

这是一个**可运行的 Godot 4 工程骨架**，用「北欧女神 1」的核心玩法（横板探索 + 按键连击/决之技战斗）套上了《山海经》的题材，目前全部用**占位色块**，方便你先跑通玩法、再逐步替换成自己的美术。

---

## 一、怎么打开和运行

1. 去 <https://godotengine.org/download> 下载 **Godot 4.x**（Windows 版，标准版即可，不用 C# 版）。
2. 解压后双击运行 `Godot_v4.x.exe`。
3. 在打开的「项目管理器」里点 **导入**，选择本文件夹里的 `project.godot`。
4. 点 **运行**（或按 `F5`），即可看到游戏窗口。

> 窗口默认 960×540，可拉动窗口任意缩放，画面会自动等比适配。

## 二、操作按键

| 按键 | 作用 |
|---|---|
| W / S 或 ↑ / ↓ | 菜单里上下选择（回车确认） |
| A / D 或 ← / → | 左右移动（升格界面里切换生命/攻击） |
| 空格 / W / ↑ | 跳跃（按住再按 J = 朝斜上发射灵石） |
| S / ↓ | 下蹲（按住再按 J = 朝斜下发射灵石） |
| J | 发射灵石：撞地形生成浮空平台 / 撞岩块击碎 / 撞魔物冻结 |
| E | 与英灵对话 / 招募 |
| T | 打开 / 关闭「英灵升格」加点界面 |
| N | 打开 / 关闭「队伍编制」界面（从图鉴挑最多 4 位出战） |
| Q / E | 升格/编队界面里翻页（英灵超过一页时；E 同时是招募键） |
| U / I / O / P | 战斗中四名队友各自连击（近战单体 / 法师范围） |
| K | 连击槽满后释放「决之技」 |
| F5 / F9 | 存档 / 读档 |

## 三、现在能玩到什么（垂直切片闭环）

启动后先到**主菜单**（W/S 选择、回车确认：新的航行 / 继续）。

1. **五个房间**：幽径入口 → 青丘之径 → 逐鹿遗迹 → 昆仑之墟 → 归墟（Boss 房），走进发光的「门」即可往返切换；HUD 左上会显示当前房间名。
2. **横板探索**：左右走、跳、蹲，用 `J` 发射灵石——灵石有三种用途：撞地形**生成浮空平台**、撞岩块**击碎障碍**、撞魔物**冻结敌人**。
3. **击碎墙通过**：幽径入口有一堵三格高的「可击碎墙」，单跳跳不过去，用灵石击碎其中一块即可通过。
4. **进入战斗**：碰到魔物 → 切入战斗画面（不想打可以先用灵石把它冻住再绕过去）。
5. **前后排站位**：近战站前排当肉盾，法师站后排施法；敌人反击优先打前排。
6. **按键连击 + 技能差异化 + 节奏**：按 U/I/O/P——近战打单体、法师放范围魔法；每位英灵有专属技能效果：**贯穿**（后羿/蚩尤）、**眩晕**（夸父/刑天/共工）、**灼烧**（祝融/烛龙）、**魅惑**（九尾狐）；每次出手后有收招冷却（轮换队友更流畅），在敌人「蓄力」期间命中判定为**完美时机**（伤害 ×1.5 + 额外连段）；命中累积「连段数」和「连击槽」，连段越高伤害越高，敌人被击飞到浮空。
7. **多目标 + 敌人图鉴 + 智能 AI + Boss**：八种魔物（梼杌/混沌/穷奇/九婴/相柳/饕餮/凿齿/相繇）散布五个房间；敌人会蓄力预警（约 0.7 秒）、25% 概率偷袭后排法师、残血狂暴（<30% 血攻击 ×1.5）、概率连招追加第二击；终极 Boss「相繇」在归墟坐镇——特大血条，二阶段（≤50% 血）喷毒、三阶段（≤30% 血）现出真身并**暴露弱点**（击中 3 次可破、削弱 Boss）；会**召唤九婴小怪**、大招为**可被打断的蓄力喷毒**。
8. **决之技 + 演出**：连击槽满 100 后按 K，闪白 + 首个活英灵立绘特写切入，对全体敌人释放全屏大招。
9. **胜负结算 + 血量持久化**：敌人全灭 → 奖励「经验水晶」，存活英灵保留当前血量（倒下的残血 1 点复活）；败北则全队回满。血量会带进下一场战斗。
10. **招募英灵**：十二位山海英灵散布五个房间，按 E 招募看身世故事；前 4 位自动出战，超出者收入「英灵图鉴」。
11. **队伍编制**：按 N 打开编队界面，从图鉴里自由挑选 / 移出出战英灵（最多 4 位）——编队立即生效，战斗按新队伍上场。
12. **英灵升格**：按 T 打开加点界面（英灵多时 Q/E 翻页），用经验水晶加生命/攻击（每点 10 水晶，生命 +10 / 攻击 +2），加的数值带进战斗。
13. **存档贯通**：招募、队伍、加点、经验水晶、当前房间、剩余血量、已购饰品、封印值、章节/剩余回合全部计入存档，读档后完整恢复（F5 存档 / F9 读档）。
14. **休息与行商**：昆仑之墟有「治疗神龛」（按 E 回满全队血量）和「行商」（按 E 用经验水晶购买全局被动饰品：聚灵玉 +50% 经验、玄武鳞 +15 生命上限、赤炎符 +2 攻击），买完立即生效。
15. **章节 / 时间配额 + 多结局**：探索界面左上角显示「章节 · 剩余回合 · 封印值」；每场战斗、每次治疗都消耗 1 个回合，招募英灵、击败 Boss 累积封印值。回合耗尽或击败 Boss 会进入结局，按封印值高低分三种：**真结局**（封印值 ≥8）、**普通结局**（不足 8）、**坏结局**（时间耗尽且未击败 Boss）。

## 四、工程结构（对照着读代码）

```
shanhai-valkyrie/
├─ project.godot                 # 工程配置：主场景、自动加载、窗口大小
├─ icon.svg                      # 图标
├─ scripts/
│  ├─ autoload/                  # 自动加载的全局单例（游戏一启动就存在）
│  │  ├─ global_state.gd         #   全局数据 + 输入绑定 + 中文默认字体
│  │  ├─ event_bus.gd            #   信号总线（场景间解耦通信）
│  │  └─ save_manager.gd         #   存档（JSON）
│  ├─ main.gd                    # 主控：主菜单 → 房间探索 ⇄ 战斗
│  ├─ player/player.gd           # 玩家控制器 + 状态机 + 发射灵石
│  ├─ exploration/room.gd        # 通用房间生成器（按数据搭地形/敌人/英灵/门）
│  ├─ world/
│  │  ├─ crystal.gd              #   灵石：生成平台 / 击碎障碍 / 冻结敌人
│  │  ├─ enemy.gd                #   巡逻敌人（可被冻结，碰到进战斗）
│  │  ├─ breakable_block.gd      #   可击碎障碍
│  │  ├─ npc.gd                  #   可招募英灵（按 E 招募）
│  │  └─ door.gd                 #   房间出口门（走进切换房间）
│  ├─ battle/battle.gd           # 战斗控制器（连击/决之技/胜负）
│  ├─ ui/
│  │  ├─ main_menu.gd            #   主菜单
│  │  ├─ hud.gd                  #   探索 HUD
│  │  ├─ upgrade_menu.gd         #   英灵升格（加点）界面
│  │  ├─ party_menu.gd           #   队伍编制界面（选 4 位出战）
│  │  └─ shop_menu.gd            #   行商商店（买全局被动饰品）
│  └─ data/
│     ├─ character_data.gd       # 英灵数据类（Resource）
│     ├─ enemy_data.gd           # 敌人数据类（Resource，含山海经图鉴描述）
│     ├─ room_registry.gd        # 房间布局数据表（加房间只改这里）
│     ├─ characters/             # 英灵数据文件（12 位）
│     └─ enemies/                # 敌人数据文件（8 种，含 Boss 相繇）
├─ art/                          # 美术贴图：丢图即生效（见 art/README.md）
└─ scenes/                       # 场景文件（都是「空壳+挂脚本」，内容由脚本生成）
   ├─ main.tscn
   ├─ battle/battle.tscn
   └─ world/crystal.tscn
```

> 本工程刻意把「场景内容」用脚本在 `_ready()` 里动态生成（而不是在编辑器里摆节点），原因是占位阶段这样改动最快、也方便你读懂每一行。等正式美术到位，可以逐步改回「在编辑器里摆 Scene 树」的标准做法。

## 五、新手学习路径（建议顺序）

1. **入门**：官方文档《你的第一个 2D 游戏》<https://docs.godotengine.org/zh_CN/stable/getting_started/first_2d_game/index.html>
2. **概念**：Node（节点）/ Scene（场景）/ Signal（信号）是 Godot 的三块基石，先搞懂。
3. **对照本工程**：按上面的结构图，从 `player.gd` 读起——它最直观（移动、跳跃、重力、状态机）。
4. **动手改**：
   - 改 `player.gd` 顶部的 `SPEED`、`JUMP_VELOCITY`、`GRAVITY`，感受「手感」变化。
   - 改 `houyi.tres` 里的 `max_hp`、`attack`，再看战斗里后羿变强了。
   - 在 `battle.gd` 的 `ENEMY_GROUPS` 表里加一行新敌人（或在 `room_registry.gd` 里改敌人 id）。
5. **加新内容**：复制 `characters/` 里任一 `.tres` 改出新英灵，再到 `room_registry.gd` 某房间的 `npcs` 里加一行坐标；复制 `enemies/` 里任一 `.tres` 即可加新敌人。

## 七、常见问题

- **中文显示成方框**：本工程已用系统字体（微软雅黑等）显示中文。若你的系统没有这些字体，改 `global_state.gd` 里 `_add_action` 下方 `get_ui_font()` 的 `font_names` 列表，换成你机器上有的中文字体名。
- **打开提示版本不匹配**：`project.godot` 里写的 `4.3`，用 4.4/4.5 打开会提示，选择「继续打开」即可（不影响运行）。
- **改了 `.gd` 报错**：Godot 编辑器底部有报错面板，贴出具体行号再排查；通常是最容易踩的几类：变量没声明、缩进用错（GDScript 用 Tab 对齐）、类型不匹配。
